# Wave Preview Player

Открытие: **Tools → Waves → Wave Preview Player** либо **Wave Inspector → Conductor Preview → Open Wave Preview Player**. Работает в Edit Mode с существующей симуляцией DirectedEnemySubWave.

## Управление

- **Play / Pause / Stop / Restart**, покадровые кнопки, скорости 0.25×–16× и **Max Speed**. Фиксированный шаг — 1/30 секунды. Max Speed показывает результат каждой пачки; Fast Seek скрывает промежуточные кадры до выбранного времени.
- **Timeline / Go To Time / полоса событий** автоматически используют Fast Seek. Выбирается ближайший действительный снимок или текущее состояние; оставшиеся шаги выполняются без ожидания игрового времени. Одновременно обрабатывается один запрос; новый заменяет предыдущий.
- При заметном расчёте показывается `Seeking` и рассчитанное время. Неполный мир скрыт до готовности выбранного кадра. Pause останавливает обычную перемотку на последнем рассчитанном кадре. Обязательный пересчёт после изменения истории или настроек сохраняется и при Pause.
- **Preview Duration** задаёт горизонт просмотра. `Use Route Duration` учитывает маршруты и задержки, но не предсказывает длительность боя по убийствам.
- Сворачиваемый **Attack Coordinator** находится внизу окна. Прежние редакторы Wave/Subwave/AttackBehaviour сохранены.

## Fast Seek и Max Speed

В **Advanced Settings** доступны **Simulation Time Budget (ms)** (по умолчанию 24) и **Max Steps Per Update** (2048). Это предел работы одной пачки, не размер шага симуляции. Шаг всегда остаётся 1/30 секунды. Один шаг, создание или восстановление снимка неделимы и иногда превышают бюджет.

В **Fast Seek Diagnostics** показаны **Target Time**, **Simulated Duration**, **Seek Wall Time**, **Simulation Speed**, **Steps Processed**. Время измеряется от последнего запроса до готовности визуального кадра; восстановленные кадры не считаются повторно выполненными шагами. Новое целевое время заменяет предыдущий запрос. Stop, Restart, смена источника и закрытие окна прекращают работу.

При перемотке не строятся промежуточные матрицы рендера и не пересчитывается поворот моделей на каждом шаге. Снимки сохраняют входные данные визуального положения, включая последний активный профиль поворота. Живые Transform источников Laser продолжают получать координаты; скрываются только рендереры. В Max Speed кадр публикуется после каждой ограниченной пачки.

Для фонового Editor при незавершённом расчёте запрашивается следующий Editor tick через тот же SignalTick API, который использует установленный Unity Pipeline. Делегат связывается один раз; если API отсутствует, используется стандартный QueuePlayerLoopUpdate. Глобальные настройки Pipeline и Time.timeScale плеер не меняет.

## Перемещение цели

**Preview Player Target** можно перемещать полем или ручкой Scene View. Текущее время, враги, снаряды, лазеры, активные атаки, Sequence и координатор сохраняются. На паузе перенос цели не продвигает симуляцию.

После начала просмотра перетаскивание автоматически включает **Record Player Movement**. В одном кадре остаётся одна запись; микроперемещения менее 0.002 единицы не записываются. При перемотке применяется положение цели из истории соответствующего кадра. Изменение в прошлом создаёт новую ветку: последующие записи удаляются, снимки после этого кадра становятся недействительными.

Обычные выпущенные снаряды сохраняют движение. Активное самонаведение получает новую цель при следующем шаге. Aim On Start и Aim On Burst сохраняют предусмотренный захват, Aim Continuous учитывает новую позицию.

Отключение **Record Player Movement** сохраняет прошлую историю и фиксирует цель с текущего кадра. **Clear Player Movement History** заменяет историю одной постоянной целью и пересчитывает выбранное время. **Stop** освобождает симуляцию и снимки, сохраняя траекторию для Restart; закрытие окна/смена волны удаляют её вместе с плеером.

## Снимки и память

**Advanced Settings → Snapshot Interval**: по умолчанию 2 секунды, настраивается от 0.25 до 30 секунд с округлением к фиксированным кадрам. **Snapshot Memory Limit (MB)**: по умолчанию 128, диапазон 16–512. Дополнительно хранится не более 32 снимков.

Кеш сохраняет начальное состояние и ближайшие новые снимки в пределах лимита. Старые промежуточные снимки освобождаются. **Clear Snapshot Cache** оставляет только начальный снимок, необходимый для корректного возврата к нулю. При перемотке восстанавливается ближайший снимок не позже выбранного времени, затем досчитывается остаток; текущее состояние используется, если оно ближе и пригодно.

Снимки содержат копии ECS-компонентов, буферов, шаблонов и флагов, состояния планировщиков, маршрутов/Phase Entry/Post Behaviour, Sequence, координатора, случайных генераторов, Child Attack и Laser/Telegraph, а также визуальные позы. При восстановлении ссылки Entity переназначаются. Сохраняется одна живая симуляция; хранилища снимков не содержат систем и GameObject. Managed-состояние копируется общим Editor-only механизмом с кешированными метаданными полей; игровая сборка не использует reflection.

Индикатор памяти и лимит относятся к **оценке размера кеша**, включая запас на native-хранилище. Это не жёсткий предел общей памяти Unity Editor, его аллокаторов, визуальных ресурсов и сборщика мусора. Начальное состояние закреплено даже при слишком маленьком лимите. Интервал и лимит следует подбирать под плотность волны.

Параметры волны, пресеты и Seed инвалидируют несовместимые снимки. Перенос цели в текущем кадре сохраняет текущий мир и префикс кеша. Все снимки освобождаются при Stop, смене волны/сцены, закрытии окна, выходе из Edit Mode и Assembly Reload. Сцены, префабы и пресеты не сохраняются плеером.

## Реализация

- `Assets/Editor/WavePreviewPlayer.cs` — транспорт, ввод и инвалидация.
- `WavePreviewPlayerWindow.cs` — окно и Scene View.
- `WavePreviewTargetHistory.cs`, `WavePreviewSnapshotCache.cs` — история цели и ограниченный кеш.
- `WaveConductorPreviewSnapshots.cs`, `EnemyProjectilePreviewSnapshots.cs`, `WavePreviewStateGraph.cs` — снимки существующей симуляции.
- `WaveConductorShootingPreview.cs` — единый шаг, сохранение сеансов подволнов и переключение их активности после отката.
- `WaveShootingPreviewPresentation.cs` — отложенное применение визуальных поз при Fast Seek.
- В `EnemyProjectileEcsSpawner.cs` добавлена только Editor-only подготовка стабильных хостов Child/Laser. Боевое поведение не менялось.

Сохранены предыдущие исправления: пустой Patrol не сбрасывает LeftBorder в центр; координатор префаба из Project учитывает сохранённую активность; панель координатора расположена внизу плеера.

## Фактическая проверка

Доработка Fast Seek, скорости 8×/16×/Max и свежие замеры: **WavePreviewFastSeek.md**. Приведённые ниже 440 проверок относятся к предыдущей доработке снимков и истории.

Проверочные скрипты — `AgentScripts/VerifyWavePreview*Snapshots.cs`, `VerifyWavePreviewSnapshotPlayer.cs`, `VerifyWavePreviewSnapshotEditor.cs`, `VerifyWavePreviewSnapshotStress.cs`. Результаты — `AgentArtifacts/wave-player-upgrade-*.json`.

- 42 проверки переноса на 20-й секунде, паузы, 30 → 10 → 30, ветвления истории, кеша, Sequence/координатора и очистки.
- 31 проверка трёх Aim Mode, повторения истории, замены запросов перемотки и сохранения обязательного пересчёта при Pause.
- 15 проверок отложенного Child Boundary Event: оба Origin Mode, Time Offset, Repeat, Sequential Sector, завершение родителя, повторное восстановление и самонаведение.
- 41 регрессионная проверка транспорта, скоростей, Child Attack, Laser/Telegraph, Sequence, координатора и сохранности глобального Unity Random.
- 265 проверок семи префабов `1_1_extrime`–`1_4_extrime`, `2_1_extrime`–`2_3_extrime`: одинаковое состояние после перемотки; сериализованные компоненты и байты файлов не меняются.
- 32 стрессовые проверки с 2048 снарядами: кеш ограничен, снимок не создаёт GameObject, многократная перемотка не накапливает ECS-миры. При лимите 16 МБ осталось 8 снимков с оценкой около 14.6 МБ; один замер восстановления ближайшего снимка — около 9 мс, без гарантии для других волн/машин.
- 10 проверок настоящего GUI и жизненного цикла окна; 4 проверки фактического Assembly Reload, после которого временные корни и все принадлежащие плееру ECS-миры освобождены.
- Всего 440 успешных проверок в восьми наборах. EditMode Test Runner содержит 0 тестов; сценарии выполнены через Pipeline в открытом Editor. Unity recompilation завершена без ошибок, обе последовательные сборки `dotnet build --no-restore` — код 0. Итоговый протокол: `wave-player-upgrade-validation.json`.
- В Console обнаружена отдельная ошибка Unity Package Manager о получении auth code Unity ID. Ошибок компиляции или Preview в итоговой проверке нет; Console не очищалась.

## Ограничения существующего Preview

Не моделируются уничтожение врагов игроком, здоровье/столкновения полноценного боя, завершение волны по убийствам и зависящие от игрока пикирования AttackBehaviour. Визуал Danger Warning остаётся в прежнем Preview; его задержка учитывается. Старые подволны без DirectedEnemySubWave пропускаются с предупреждением. Отдельных маркеров событий Child/Laser на Timeline пока нет.

Сохранён лимит 2048 живых снарядов и ограничения Child Attack; пропуски видны в окне. История событий ограничена 12000 записями. Один неделимый шаг или создание снимка на плотной волне могут превысить бюджет обновления. Полный боевой проход в Play Mode и производительность на мобильном устройстве не проверялись.
