# Attack Sequence

В `DirectedWaveAttackBehaviour` выберите **Attack Behaviour Mode → Sequence**. Режим **Patterns** сохраняет прежнюю конфигурацию групп и Single/Multiple внутри каждого паттерна; переключение её не очищает. Старые волны по умолчанию используют Patterns.

## Общие настройки

| Поле | Значение |
|---|---|
| Sequence Mode | Once — один проход; Loop — проходы вперёд; PingPong — вперёд/назад без повторного запуска крайних шагов подряд; Random — перемешивание корневых шагов на каждом проходе |
| Loop Count | Количество проходов. 0 — бесконечно. В Once не используется |
| Start Step | Индекс корневого шага с нуля. Применяется к первому проходу. В Random выбранный шаг идёт первым, остальные перемешиваются |
| Restart On Reentry | Начать сначала при новом входе в post timeline/повторном включении компонента. Выключено — сохранить прогресс; прерванное выполнение текущего шага запускается заново |
| Wait For Previous Attack | Перед следующим запуском дождаться предыдущих активных атак. Ожидание дочерних запусков включается отдельно у шага |
| Seed | Детерминированный порядок Random. Глобальное состояние Unity Random не изменяется |

Возвращение отдельного врага из пикирования завершает его атаку, но не перезапускает всю Sequence. У существующего планировщика группы сохраняются собственные правила выбора атакующих.

## Шаги

**Attack** содержит существующие настройки Directed Wave Attack Pattern и необязательный Attack Preset. Сохранены Fire Mode, Aim Mode, Enemy Settings/Wave Override, Single/Multiple, Burst, Emission Origin/Layout, Fan/Stack/Spread, Rotation, Projectile Settings, пикирования и Local Overrides.

- **Step Start Delay** — задержка перед шагом, один раз до всех его повторений.
- **Repeat Count** — количество полных выполнений шага.
- **Wait For Completion** — дождаться завершения перед следующим повторением/шагом.
- **Delay After Step** — задержка после всех повторений.
- **Attack Speed Multiplier** — множитель расписания группы, интервалов залпов/Burst/Sector, Attack Cooldown и вращения паттерна. Количество залпов, скорость полёта пуль и индивидуальные времена дочерних паттернов не изменяются.
- **Target Slots Override** — использовать выбранные слоты вместо общего выбора AttackBehaviour. Настройки Local Overrides этих слотов сохраняются.

Одно выполнение шага — конечный цикл существующего контроллера группы: каждый выбранный враг выполняет настроенное `Attacks Per Enemy Per Cycle`. Внутренние `Attack Shot Count` и Burst продолжают работать. Поэтому Repeat Count умножает полные атаки, а не число отдельных пуль.

**Pause** содержит длительность паузы, Start Delay, Repeat Count и Delay After Step.

**Repeat Block** повторяет вложенный список без копирования элементов. Внутри возможны другие блоки; максимальная глубина — 8. Содержимое блока сохраняет свой порядок, в том числе при Random/PingPong корневой последовательности. Паузы вокруг части последовательности добавляются отдельными Pause-шагами.

У шагов есть включение/выключение, имя, сворачивание, перемещение ↑/↓, Duplicate и Remove. Дублирование создаёт независимую копию вложенных данных. Изменения выполняются через SerializedProperty с Undo/Redo и Prefab Overrides.

## Завершение и перекрытие

Завершение включает залпы всех Single/Multiple-паттернов, Burst, фактические отложенные запуски Sequential Sector, возврат из движения атаки и Attack Cooldown. `Delay After Step` — дополнительная задержка.

При отключённых ожиданиях шаги могут перекрываться на разных слотах. Общий слот занят до завершения своего текущего выполнения: новый шаг ждёт освобождения, сохраняя активный паттерн. Sequence удерживает управление выбранными врагами во время пауз, чтобы их автономная стрельба не нарушала порядок.

**Wait For Child Attacks** по умолчанию выключен. Если включён, учитываются реальные отложенные/событийные дочерние и вложенные запуски. Оставшийся полёт обычных пуль и самостоятельный визуальный эффект завершению не мешают.

- **Child Wait Timeout** по умолчанию 10 секунд: после этого Sequence продолжает выполнение, а созданные эффекты могут продолжаться.
- **Unlimited Child Wait** — явное разрешение неограниченного ожидания. Например, Expired-триггер у снаряда с очень долгой жизнью способен удерживать такой шаг.
- Ожидание детей применяется там, где включён completion gate: Wait For Completion шага или общий Wait For Previous Attack. Без этих gate переход не блокируется.
- В Preview показывается число достигнутых ограничений ожидания детей.

## Пример

1. Attack `Aimed`: Wave Override, один залп в паттерне, Repeat Count = 3. Интервал между полными атаками задаётся Attack Cooldown.
2. Attack `Radial`: Emission Layout = Radial, Repeat Count = 1.
3. Pause: нужная длительность.
4. Attack `Sector`: Emission Layout = Sector, при необходимости Sequential и Layout Rotation.
5. Sequence Mode = Loop, Loop Count = 0.

## Preview

Используйте обычный Preview Wave, In Formation или Preview Wave Schedule. Порядок, блоки, задержки, Seed и completion gates исполняются тем же Sequence Player, что и в Runtime. Видно имя текущего шага. Изменение компонента или назначенного пресета пересоздаёт Preview с пересчётом истории; остановка/перемотка освобождает временные объекты и ECS-миры.

Статические Scene View guides показывают первый подходящий паттерн для слота; анимированный Preview исполняет последовательность целиком. Сохраняются существующие ограничения Preview по числу одновременно симулируемых снарядов и отсутствие полной симуляции зависимых от игрока пикирования. Полёт снарядов и Child Attack используют существующие ECS-системы.

## Реализация и проверки

- `DirectedWaveAttackSequence.cs` — модель, курсор блоков и общий проигрыватель.
- `DirectedWaveAttackSequenceRuntime.cs` — конечные циклы существующего контроллера и владение слотами.
- `EnemyAttackCompletionTracker.cs` — завершение дочерних атак.
- `DirectedWaveAttackSequenceEditor.cs` — Inspector.
- `WaveShootingPreviewSequence.cs` — исполнение Sequence в существующем Preview.

Проверки и логи: `sequence-Verify*.json`, `sequence-final-compatibility-*.json`, `sequence-*-build.log` в AgentArtifacts. Префабы существующих волн автоматически не переводились в Sequence и не пересохранялись.
