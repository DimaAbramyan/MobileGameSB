# Исправление чередования групп после уничтожения врагов

Проблемная волна: `Assets/Waves/2/2_2_extrime.prefab`.

В Play Mode через Pipeline записаны состояния координатора и контроллеров атак: `wave-phase-observation-20261019-103824.jsonl`, `wave-phase-observation-20261019-103926.jsonl`. К моменту подключения вторая запись уже относилась к следующей волне; это ограничивает полноту наблюдения исходного момента уничтожения. Настройки нужной волны сохранены отдельно в `wave-phase-active-configuration.json`. Пользователь подтвердил `2_2_extrime`.

Подтверждённые причины:

1. `WaveAttackCoordinatorPlayer` снова добавлял уничтоженные подволны при повторной активации. При `On Enemy Death = CompleteGroup` старая смерть немедленно завершала каждое новое окно атак. Выжившие лишались разрешения стрелять. Теперь участник, уничтоженный до начала текущего окна, пропускается. Новая смерть во время окна по-прежнему обрабатывается согласно выбранному правилу.
2. `Restart` в `DirectedWaveAttackBehaviour` очищал `nextAttackReadyTimes` вместе с состоянием контроллера. Это позволяло начать стрельбу до окончания заданной перезарядки, если соседняя группа завершилась раньше. Теперь Restart сбрасывает последовательность выстрелов, сохраняя сроки cooldown живых врагов по их собственным часам. Сохраняются отдельные сроки контроллеров Multiple Patterns. Обычные Stop/Begin вне реактивации координатором не изменены.

Пауза `Delay After Group = 2` в координаторе сама по себе не терялась: проверка до исправления уже проходила. Ошибку раннего выстрела давал сброс cooldown при Restart. Изменение синхронизировано с `WaveShootingPreviewCoordinator`.

Настройки prefab, значения cooldown/duration, режимы Restart/Resume и On Enemy Death не переназначались. Если нужно продолжать текущую фазу при потере целой подволны, используйте `On Enemy Death = SkipParticipant`; `CompleteGroup` намеренно завершает текущую фазу при новой потере участника, но больше не завершает следующие фазы из-за той же смерти.

Проверки:

- `VerifyWavePhaseDeathRegression`: до исправления воспроизводились потеря повторного окна и сброс cooldown; после исправления все 12 сценариев прошли.
- `VerifyWaveAttackCoordinator`: 50 проверок прошли — переключение, перекрытия, циклы, Preview, Interrupt/Resume, Burst и отложенный Sector.
- Unity recompile/domain reload завершены без ошибок компиляции.
- Обе сборки `Assembly-CSharp.csproj` и `Assembly-CSharp-Editor.csproj` с `--no-restore --verbosity:quiet --nologo` успешны. В игровой сборке 118 предупреждений существующих полей/зависимостей, в редакторской 0; ошибок 0.
- Хэш prefab до/после изолированных проверок совпал.

Повторный полный бой после исправления не запускался. Следующий запуск Play Mode использует исправления. Для проверки поведения нужно частично уничтожить одну из групп, дождаться её следующего окна, затем быстро уничтожить соседнюю группу до окончания cooldown первой.

Diff именно этой задачи: `wave-phase-task.diff`. Изначальные изменения рабочего дерева сохранены.
