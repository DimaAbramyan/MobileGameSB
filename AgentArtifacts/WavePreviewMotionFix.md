# Исправления Preview для 1_4_extrime

- `WaveShootingPreviewSession.CreateEnemyVisual`: отрицательный Scale X у `FourWayEnemy` делился на `Max(0.0001, scale)`. Визуальный размер получался порядка 13333 единиц. Preview теперь копирует только нужную иерархию Transform/SpriteRenderer с исходными локальными позами, отражениями и настройками размера спрайтов. Сценарии, коллайдеры и другие игровые компоненты не клонируются. Это также сохраняет вложенные повороты и неравномерный масштаб без потери shear при уплощении иерархии.
- Layout Rotation сбрасывала время в начале каждого нового цикла атаки. В группе FourWay с одиночными выстрелами это давало почти постоянное направление вместо PingPong-поворота. Теперь часы привязаны к профилю и продолжаются между атаками, как у Runtime executor. Для входного маршрута часы начинаются при запуске соответствующей входной атаки. Новое состояние автоматически входит в снимки Preview.

Проверка: 21 проверка визуалов, 265 сравнений реальных выстрелов Runtime/Preview в трёх режимах вращения, 125 проверок существующей волны, 41 регрессия транспорта и 31 проверка Aim/history. Отдельно прошли восстановление ECS-снимков, продолжение после отката и задержанные подволны. Итоговый протокол — `wave-preview-motion-validation.json`.

В `1_4_extrime` проверены отметки 2, 5, 10, 15, 20 и 30 секунд. Гигантские модели отсутствуют; максимальная диагональ обычной модели — около 2.84 единицы. Повторное вычисление с нуля и восстановление снимков дают одинаковый результат. Байты префаба, сериализованные данные и dirty flag сцены не изменены.

Unity recompile завершена без ошибок; обе последовательные dotnet-сборки завершились с кодом 0. Новых ошибок Console после начала проверки нет. Индекс MCP обновлён. Проверка выполнялась в Edit Mode, без запуска полного боя.

Окно оставлено на 5-й секунде в уже открытом Prefab Stage `1_4_extrime`. Снимок Scene View: `wave-preview-motion.png`. Исходные настройки волны и префабов не перенастраивались.
