# Пулемёт — первая подборка

Дата проверки: 26 октября 2026. Каталог: http://127.0.0.1:8765.

Все варианты допускают коммерческое использование по указанным лицензиям. Для CC BY нужно сохранить указание автора, ссылку на источник и лицензию, обозначить изменения и не вводить запрещённых лицензией дополнительных ограничений. Готовый текст для каждого файла сохранён в `dist/licenses/<sound-id>/attribution.txt`.

Версии для сравнения: mono PCM16 WAV / 44,1 кГц, пик −9 dBFS, удаление стартовой паузы/сокращение хвоста там, где это требовалось, короткие fade по краям. Высота тона не менялась. Одинаковый пик не означает одинаковую воспринимаемую громкость. Исходные OGG/WAV/MP3 сохранены побайтно; контрольные суммы есть в `catalog.js` и `source.txt`.

Кнопка **«10 выстр./с»** воспроизводит 20 наложенных повторений одного выстрела с интервалом 100 мс, без рандомизации. Это служебная иллюстрация быстрого повторения, а не дополнительный найденный вариант. Она помогает самостоятельно проверить навязчивый тон, наложение хвостов и утомительность. Кнопка **«С начала»** возвращает одиночный выстрел.

В Unity/FMOD ничего не импортировано.

Проверено: все 30 аудиофайлов полностью декодированы ffmpeg и воспроизведены до конца в открытом браузере (автопроверка с выключенным звуком); пройдены проверки метаданных, наличия исходников, лицензий и SHA-256. Файл выбора не изменился. Обе C#-сборки прошли без ошибок и предупреждений.
