# Локальный каталог звуков

Запуск: двойной щелчок по **Open Catalog.cmd** (нужен установленный Python 3).
Адрес: **http://127.0.0.1:8765**. Если сервер уже работает, запуск откроет существующий каталог.
Из терминала: `python serve.py --open`. Для остановки сервера в терминале — Ctrl+C.

Новые подборки ракетного оружия: [Rocket Launch — 20 вариантов](http://127.0.0.1:8765/?category=rocket-launch) и [Rocket Explosion — 20 вариантов](http://127.0.0.1:8765/?category=rocket-explosion). Короткие игровые SFX с выровненной громкостью, неизменёнными оригиналами и отдельной предварительной пятёркой для каждой категории. Источники, лицензии и проверки — в [SEARCH-rockets.md](SEARCH-rockets.md).

[Continuous Laser — 13 разных Loop-кандидатов](http://127.0.0.1:8765/?category=continuous-laser): Soft Energy Beam (4), Electric Beam (2), Plasma Beam (1), Arcade Laser (1), Ambient Energy (5). В карточках доступны оригиналы и 60-секундные повторы. До 20 подборка не дополнена неподходящими эффектами или дублями. Источники, лицензии, ограничения и проверки — в [SEARCH-continuous-laser.md](SEARCH-continuous-laser.md).

Новая подборка: [Flamethrower · Stylized / Arcade — 21 кандидат: 13 Loop, 7 Start, 1 End](http://127.0.0.1:8765/?object=flamethrower-arcade). Готовые игровые энергетические потоки, магия и sci-fi из 17 библиотек. Источники, лицензии и проверки — в [SEARCH-flamethrower-arcade.md](SEARCH-flamethrower-arcade.md).

Прежние [реалистичные Flamethrower — 21 кандидат: 16 Loop, 4 Start, 1 End](http://127.0.0.1:8765/?category=flamethrower) сохранены для сравнения. Для непрерывного потока включите существующий «Повтор» в нижней панели. Перспективные пятёрки отмечены отдельно от вашего избранного. Подробности прежнего отбора — в [SEARCH-flamethrower.md](SEARCH-flamethrower.md).

[24 кандидата для пулемёта](http://127.0.0.1:8765/?object=machine-gun-v3) сохранены; подробности — в [SEARCH-machine-gun-v3.md](SEARCH-machine-gun-v3.md).

`dist/index.html` также открывается напрямую без сервера и интернета. В этом режиме отметки сохраняются только в браузере; файловое хранилище доступно через сервер. Рекомендуется пользоваться постоянным адресом выше. Все стили, скрипты и аудио локальные, внешних зависимостей нет.

## Прослушивание и выбор

- Фильтруйте по категории, объекту, лицензии и тексту.
- Плеер в карточке воспроизводит локальный файл. «Один выстрел» возвращает одиночный эффект. У новых вариантов отдельно доступны пять вариаций и очереди 5 / 10 / 15 выстр./с.
- Выбор вариации в списке сразу переключает плеер и запускает выбранный одиночный выстрел. «Один выстрел» повторяет эту вариацию; фильтрация и обновление карточек сохраняют её в текущем сеансе. Очереди 5 / 10 / 15 выстр./с содержат перемешиваемый набор пяти вариаций.
- «Сравнить варианты» запускает объект; «Слушать по порядку» — все видимые результаты. Между файлами пауза 0,4 секунды. Одновременно играет один эффект.
- Нижняя панель: предыдущий/следующий вариант, пауза, остановка, повтор одного файла и общая громкость. Корзина рядом с избранным мгновенно переносит текущий трек в Removed без подтверждения; при прослушивании из Removed эта кнопка восстанавливает его. Горячие клавиши вне полей ввода: пробел и стрелки ← →.
- Панель автоматического плеера доступна по умолчанию для всех категорий оружия, включая Flamethrower и Continuous Laser. Корзина возле списка кандидатов переносит выбранный трек в Removed через тот же механизм, что и кнопки в карточках. При удалении воспроизведение останавливается; защита от повторного импорта сохраняется.
- После удаления выбранного эффекта плеер выбирает следующий в текущем отфильтрованном списке, а с конца — первый оставшийся. Обычное воспроизведение продолжается на следующем треке; пауза и повтор сохраняются. Автоматическая стрельба останавливается, следующий кандидат выбран для нового удержания. Если список опустел, плеер останавливается. Удаление другой карточки не меняет выбранный трек.
- Панель «Автоматическая стрельба» проверяет одиночные выстрелы в реальном времени. Выберите кандидат в списке либо кнопкой «◎ Авто» в карточке. Удерживайте «Удерживать огонь» мышью/касанием или пробелом/Enter на кнопке. Отпускание, потеря фокуса окна и скрытие вкладки останавливают звук. Стрелки ← → во время удержания переключают кандидат; кнопки со стрелками и список доступны между пробами.
- Темп 1–30 выстр./с, быстрые кнопки 5/10/15, лимит 1–8 голосов (по умолчанию 3). При превышении лимита старый хвост плавно снимается. Уровень каждого голоса делится на лимит, оставляя запас при наложении; сравнивайте кандидатов при одинаковом лимите. Общая громкость синхронизирована с нижней панелью. Выбранная вариация старых дизайнов используется и в живом режиме.
- Звёздочка добавляет в избранное. Она доступна в карточке, рядом с текущим звуком в нижнем плеере и рядом с выбранным кандидатом в панели автоматической стрельбы; все три места синхронизированы. Под каждым вариантом можно оставить заметку.
- Корзина справа в карточке **сразу убирает трек без подтверждения**. Все его собственные файлы переносятся в `dist/Removed/<id>/files/`; общие исходники копируются, чтобы не нарушить другие треки. В разделе **Removed** можно слушать отклонённые варианты, читать происхождение и вернуть их кнопкой ↶ в исходную категорию. Избранное и заметки сохраняются. Если перенос не удался, карточка возвращается с сообщением об ошибке. Для этих операций нужен сервер `Open Catalog.cmd`, режим `file://` не может перемещать файлы.
- Метка «Перспективный кандидат» и пояснение выделяют предварительную пятёрку в новых подборках. Она независима от ваших звёздочек; все остальные кандидаты остаются доступны. Если метки есть, появляется фильтр «Перспективные · топ-5».
- При серверном запуске отметки автоматически сохраняются в `data/selections.json` и дополнительно в localStorage браузера. Файл записывается атомарно. Для каждого ID сохраняется более свежая отметка, включая снятие звёздочки; добавление звуков не сбрасывает выбор.
- «Экспорт выбора» сохраняет резервный JSON. «Импорт» объединяет его с текущими отметками: выигрывает более свежая версия каждой записи. Для намеренного возврата к старому состоянию используйте резервную копию `data/selections.json` при остановленном сервере.
- Выбор из режима `file://` можно перенести в серверный через экспорт/импорт.
- «Проверить звук» воспроизводит тихий синтетический WAV длительностью 1 секунду. Это служебный тест, он не входит в подборку игровых эффектов. Его можно пересоздать командой `python make_check_audio.py`.
- Адрес `http://127.0.0.1:8765/?check=audio` запускает браузерную автопроверку WAV с выключенным звуком; результат до перезапуска сервера доступен по `/api/playback-check`. Проверяются реальное воспроизведение и событие окончания. Слышимость в динамиках проверяется кнопкой «Проверить звук».
- `?check=catalog` проверяет в браузере все видимые одиночные файлы, вариации, очереди, исходные компоненты и оригиналы с выключенным звуком. Результаты доступны через `/api/playback-check` до перезапуска сервера. Параметр `verifyRate=4` ускоряет только технический тест; он не используется для оценки тембра. Это проверка декодирования и окончания воспроизведения, а не прослушивание в динамиках.
- `?object=machine-gun-v2&check=variations` проверяет именно переключение списка вариаций, фактический источник плеера и сохранение вариации при пересоздании карточки и повторном запуске.
- `?object=machine-gun-v3&check=automatic` проверяет смену источника через список и стрелки, кнопки темпа, регуляторы темпа/голосов и реальный офлайн-рендер Web Audio: 24 кандидата × 4 темпа (5/10/15/30) × 2 лимита (1/3). Контролируются число выстрелов, лимит голосов, непустой сигнал и пик. Это 192 технические проверки без вывода звука в динамики. Они не подтверждают работу физического удержания или субъективный комфорт. Отдельные регрессионные проверки отмены загрузки, смены кандидата и остановки запланированных хвостов: `node tools/test_automatic_fire.mjs`.
- «Режим сравнения» выбирает одиночный выстрел либо очередь 5 / 10 / 15 выстр./с для последовательного сравнения и перехода стрелками. Кнопки в карточках запускают конкретный файл. Если выбранного темпа у старой записи нет, воспроизводится одиночный файл; подпись под плеером показывает фактический режим.
- [Предыдущие шесть дизайнов пулемёта](http://127.0.0.1:8765/?object=machine-gun-v2&mode=10): по пять вариаций и по три 12-секундные очереди. Сравнение выровнено по громкости при 10 выстр./с примерно до −26 LUFS. Источники CC0, авторство не обязательно. Подробности — в `SEARCH-machine-gun-v2.md`.
- Новая подборка v3 содержит 20 неизменённых WAV из бесплатных выборок Sonniss GDC разных студий и четыре публичных HQ MP3-превью Freesound (исходный WAV Freesound требует входа на сайт). Для сравнения отдельно сохранены короткие PCM24/48 кГц версии с выровненной громкостью: −26 LUFS ±0,1 на эталонной последовательности 40 выстрелов за 4 секунды до деления уровня на лимит голосов. Длительности 0,16–0,30 с; метод и точные фрагменты указаны в карточках. Новые синтетические слои не создавались.
- У 20 записей Sonniss действует GDC License 2.0, допускающая коммерческие игры без атрибуции, но запрещающая распространение записей как библиотеки/семплов и обучение AI/ML. Каталог хранится локально для вашего проекта. Две записи Freesound — CC0, две — CC BY 4.0 с обязательным авторством, ссылками на источник/лицензию и указанием обработки. Готовые тексты и сохранённые страницы лицензий находятся в `dist/licenses/<id>/`.
- Прежняя подборка пулемёта сохранена как отдельный объект. Её короткие тесты из 20 выстрелов и нормализация по пику −9 dBFS сохранены. Их уровень отличается от новой подборки; сравнивайте внутри одной подборки.

## Порядок дальнейшего поиска

1. Получить от пользователя конкретный объект/оружие/механику. Не составлять весь список игры и не искать звуки заранее.
   Перед поиском прочитать **весь** `dist/Removed/index.json` и активный `dist/catalog.js`. Не предлагать отклонённые записи повторно. До создания активных файлов вызвать `ImportGate.allow(id, source_path, source_metadata)`, а фиксацию выполнять только через `CatalogStore.import_records(records, categories, objects)`. Все действующие импортёры уже используют этот путь; прямую запись `catalog.js` не добавлять. Подробности и воспроизводимые проверки: [REMOVED.md](REMOVED.md).
2. Искать только этот запрос в нескольких бесплатных библиотеках, включая смежные категории. Цель — **20–30 различных качественных готовых эффектов** с профессиональным звучанием. Вариации одного семпла, сдвиги высоты, изменения громкости и демонстрации повторения не считать отдельными кандидатами. Предпочитать разнообразие тембра, фактуры и ощущения механики. Если хороших записей 17, сохранить 17 и сообщить об этом; не добирать количество неподходящими файлами или простым самостоятельным синтезом.
3. Проверить лицензию именно загружаемого файла по первоисточнику. Предпочитать CC0. Для других лицензий зафиксировать коммерческие права, точные условия и готовую атрибуцию. Не брать NC/personal-only или неясные разрешения. Автоматическая проверка метаданных не заменяет чтение лицензии.
4. Отобрать записи с учётом десятков и сотен повторений: избегать примитивных писков, резкого верха, чрезмерных атак и навязчивых резонансов. Скачать неизменённый оригинал в `dist/audio/<category-id>/<object-id>/<sound-id>/originals/`, превью хранить отдельно. Выравнивать **воспринимаемую громкость** превью внутри подборки с одинаковой методикой и запасом пиков; не ограничиваться нормализацией по пику. Для очень коротких звуков сравнивать измерения сопоставимых последовательностей, а для разных темпов одного кандидата применять общее усиление. Фиксировать метод, усиление, громкость и пики в обработке/отчёте. Если требуется перекодирование, описать его. Автоматические измерения не доказывают приятность звука; технический автотест не называть прослушиванием на слух.
5. Сохранить доказательства происхождения в `dist/licenses/<sound-id>/`: `license.txt` (условия, ссылка, дата проверки), `source.txt` (страница, автор, URL файла, даты), при необходимости `attribution.txt`. При наличии сохранить исходный LICENSE из архива.
6. Дополнить `dist/catalog.js`, сохраняя все прежние записи и ID. Не менять `catalogId`. Категории/объекты добавлять только для выполненных запросов. Отдельно отметить пять наиболее перспективных кандидатов с краткими причинами через `shortlist` (при менее пяти — отметить найденных). Это предварительная пятёрка, а окончательный выбор и пользовательское избранное остаются за пользователем.
7. Запустить `node validate.mjs`, `node --check dist/app.js`, обновить каталог, проверить реальные файлы и самостоятельно открыть его в браузере. В результате сообщить количество самостоятельных кандидатов, отметить пятёрку, дать ссылку на каталог и описать ограничения проверки.
8. Не импортировать в Unity/FMOD и не менять настройки проекта без отдельного разрешения.

## Формат catalog.js

Файл содержит `window.SOUND_CATALOG = { schemaVersion: 1, catalogId: "sci-fi-bullet-hell-sfx", updatedAt: "YYYY-MM-DD", categories: [], objects: [], sounds: [] };`.

Категория: `{ id: "category-slug", name: "Название категории" }`.

Объект: `{ id: "object-slug", categoryId: "category-slug", name: "Название объекта", description: "Краткий контекст запроса" }`.

Шаблон записи **для заполнения проверенными данными**, не готовый результат:

```js
{
  id: "stable-sound-id",
  objectId: "object-slug",
  title: "Название варианта",
  description: "Характер звука и почему подходит; возможные ограничения.",
  tags: ["короткий", "электронный"],
  file: "audio/category-slug/object-slug/stable-sound-id/original.wav",
  originalFilename: "точное исходное имя.wav",
  downloadedAt: "YYYY-MM-DD",
  sha256: "64 шестнадцатеричных символа SHA-256 локального файла",
  source: {
    name: "Название библиотеки",
    url: "https://.../страница-конкретного-эффекта",
    author: "Имя автора",
    downloadUrl: "https://.../исходный-файл-или-архив"
  },
  license: {
    id: "CC0",
    name: "CC0 1.0",
    url: "https://.../точные-условия",
    commercialUse: true,
    attribution: "Атрибуция не требуется.",
    verifiedAt: "YYYY-MM-DD",
    evidenceFile: "licenses/stable-sound-id/license.txt"
  }
}
```

`sha256` относится к файлу из `file`; при обработке также фиксируйте контрольную сумму оригинала и преобразования в `source.txt`. Не переименовывайте/перенумеровывайте ID существующих записей. Не удаляйте `data/selections.json` при обновлении каталога.

Предварительная рекомендация хранится в необязательном поле записи `shortlist: { rank: 1, reason: "Почему запись перспективна для этой механики; ограничения" }`. Ранги 1–5 уникальны в пределах объекта, пояснение обязательно. Это метаданные подбора, они не записываются в пользовательское избранное. В старых подборках метки автоматически не проставляются.

Дополнительные поля нового дизайна: `variants` (пять файлов с постоянными ID и SHA-256), `auditions` (темп, файл, длительность, метрики и журнал событий), `layerSources` (автор, первоисточник, ссылка скачивания, исходный файл, SHA-256 и лицензия каждого записанного слоя), `stemFiles` (компоненты до финальной обработки) и `recipeFile`. Для `source.kind = "procedural"` источником служит локальный рецепт, а не вымышленная внешняя библиотека.

Оригинальные записи новой подборки: `dist/audio/_sources/machine-gun-v2/originals/`. У каждого дизайна папка `originals/` содержит компоненты до финальной обработки, `processed/` — готовые одиночные выстрелы, `demos/` — очереди и журналы событий. Детерминированный рецепт — `dist/recipes/design_machine_gun_v2.py`; требует Python 3, NumPy, ffmpeg/ffprobe и сохранённые исследовательские файлы в `.local/research/`. Прослушиванию Python-библиотеки и ffmpeg не нужны.

## Структура

```text
SoundCatalog/
  Open Catalog.cmd
  serve.py                    # localhost, отдаёт только dist/ и API отметок
  validate.mjs                # проверка метаданных, локальных файлов и SHA-256
  make_check_audio.py         # генератор служебного теста
  data/selections.json        # появится при первом серверном сохранении
  dist/
    index.html
    styles.css
    app.js
    catalog.js                # накопленные результаты со стабильными ID
    automatic-fire.js         # живое воспроизведение и ограничение голосов
    audio/                    # организованные локальные аудиофайлы
    licenses/                 # источники и доказательства лицензий
```

Сервер слушает только `127.0.0.1`; интернет не нужен. Файлы вне `dist/` через него не публикуются. Порт фиксирован для постоянства browser storage; при конфликте сервер сообщает об ошибке вместо молчаливой смены порта. Разрешён явный запуск с `--port ЧИСЛО` (выбор на диске общий, browser storage привязан к адресу).

Импорт v3 воспроизводим: `python tools/import_machine_gun_v3.py` (NumPy, ffmpeg и сохранённые исходники из `.local/research/machine-gun-v3/`). Он не скачивает файлы, не генерирует звук и не меняет отметки. В `originals/` находятся неизменённые скачанные файлы, в `processed/` — превью и `preparation.json` с параметрами обработки. Для прослушивания эти инструменты не нужны.
