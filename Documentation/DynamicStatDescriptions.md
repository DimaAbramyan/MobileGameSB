# Динамические описания

Откройте WeaponMetaConfig → Description либо ShipMetaConfig → Active Ability
Description / Passive Ability Description.

1. Напишите предложение в многострочном поле. Поставьте курсор в нужное место.
2. Нажмите Insert Stat и выберите источник в том же меню, что у StatBox.
   Вставится автоматически созданный токен, например `{stat1}`. Пути/ID вводить не нужно.
3. Продолжайте писать текст вокруг токена. В списке под текстом можно заменить
   характеристику, задать Value Format (`0.0`, `{0:0.##}%`, `{0:0.##} м`),
   повторить вставку кнопкой Insert Again или удалить привязку крестиком.
   Крестик удаляет все её вхождения; одно вхождение можно стереть непосредственно в тексте.
4. Preview показывает итоговое предложение на базовой Meta. Bold Values и Color Values
   оформляют только динамические значения через TMP Rich Text.

Меню использует полный StatCatalogBuilder/StatCatalogEditorCache, независимо от
карточек Base Stats/Secondary Stats. Доступны те же 639 текущих дескрипторов:
числа, строки, enum, вычисляемые значения, вложенные снаряды и способности.
Общая StatValueFormatter используется и карточками, и описаниями. [base], [missing]
и [format] имеют те же значения. При недоступной привязке Inspector предупреждает,
а источник с похожим названием автоматически не подставляется.

В NewMainMenu подключены существующие TMP-тексты Description в InfoWeapon и два
текста описаний в InfoBody раздела CraftMenu. StatDescriptionView получает полный
каталог и тот же IStatValueResolver из своего StatBlocksView и слушает ValuesRefreshed.
Поэтому ProgressChanged и Bind(runtime) обновляют текст вместе с карточками без
создания игровых экземпляров и поиска элементов сцены в Update. Пустые новые
описания сохраняют прежний текст из ContentDefinition как совместимый fallback.

Localized Sentence поддерживает обычные и Smart-записи Unity Localization.
В String Table включите флаг Smart у нужной записи. Формы слов задаются в переводе:

```
ru: Имеет {stat1} {stat1:plural:заряд|заряда|зарядов}.
en: Has {stat1} {stat1:plural:charge|charges}.
```

Insert Stat создаёт ту же привязку `{stat1}`; её можно повторять и менять порядок
в переводе. Числовой аргумент передаётся Plural Formatter как исходное число.
Культура чисел и правила множественного числа берутся из активной Locale Unity.
Для предварительного просмотра выберите Preview Locale: `ru`, `en`, `ru-RU` и т. п.
Inspector читает соответствующий перевод и показывает предупреждение, если его нет.

Голый `{stat1}` использует Value Format и существующее оформление значений, например
`{0:0.0}%`. Явный формат в переводе `{stat1:N1}` обрабатывается Smart Formatter один
раз, без предварительного Value Format. Для явных Smart-выражений Rich Text можно
задать непосредственно в переводе. Обычные LocalizedString и Meta без локализации
продолжают поддерживать старые токены. Если обычная запись использует `{stat1:...}`,
нужно включить Smart: Inspector предупреждает, UI показывает `[format: enable Smart]`.

Смена локали повторно загружает исходную запись String Table, а смена характеристик
переформатирует её без повторной загрузки. Устаревшие асинхронные ответы после смены
предмета игнорируются. Пока перевод загружается, используется текст Meta.
Ошибки локализации отмечаются `[localization]`, отсутствующие значения — `[missing]`.

Проверка улучшения: сфокусируйте предмет с описанием, содержащим Damage, и улучшите
его в существующем UI. Карточка и вставка получают новый уровень из одного контекста.
Для временных модификаторов задайте Runtime Source существующему InfoController.

Проверки: VerifyStatDescriptions.cs запускается в Play Mode (639 сравнений полного
каталога плюс 13 проверок шаблонов/сериализации/компонента); VerifyStatBlocksScene.cs
проверяет фокус, совместное обновление 20 → 25 и отсутствие устаревшего описания.
VerifySmartDescriptions.cs проверяет Plural Formatter ru/en, десятичные разделители,
Value Format, типизированные аргументы, enum и строковые значения.
